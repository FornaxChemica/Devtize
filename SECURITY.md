# Security Policy

Devtize is pre-release Phase A software. Please do not open a public issue for a suspected vulnerability. Instead, use GitHub's private vulnerability reporting for the `FornaxChemica/devtize` repository once it is published. Until that private channel exists, retain the report and contact the repository owner privately.

Include the affected version or commit, reproduction steps, expected impact, and whether credentials or destructive behavior may be involved. Never include live credentials, private repository contents, or unrelated environment data.
